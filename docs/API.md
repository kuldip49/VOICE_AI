# API reference

Interactive docs (generated by FastAPI): **http://127.0.0.1:8000/docs**. All bodies are JSON and validated; errors return `{"detail": ...}`.

Admin endpoints require header `X-Admin-Key` **only when** `ADMIN_API_KEY` is set.

## Public (customer-facing)
| Method | Path | Body / query | Returns |
|---|---|---|---|
| GET | `/api/health` | | `{status, llm}` |
| GET | `/api/settings/public` | | company/agent name, voice settings, scoring weights, provider status |
| POST | `/api/conversations` | `{language: en|hi, channel: text|voice, customer_id?}` | conversation + greeting message |
| POST | `/api/conversations/{id}/messages` | `{text (1-2000 chars), channel?}` | user message, assistant message (sources, generated_by, intents), tool_calls, sentiment, lead, customer |
| GET | `/api/conversations/{id}` | | conversation with messages, customer, lead |
| POST | `/api/conversations/{id}/end` | | ends + creates/updates call summary |
| GET | `/api/appointments/slots` | `?date=YYYY-MM-DD&limit=` | free slots |

Rate limited per IP (`RATE_LIMIT_PER_MINUTE`, 429 when exceeded).

## Admin (CRM / dashboard)
| Method | Path | Notes |
|---|---|---|
| GET | `/api/conversations` | recent conversations |
| GET | `/api/conversations/{id}/tool-logs` | agent tool audit log |
| GET | `/api/leads?q=&category=HOT|WARM|COLD&status=&sort=recent|score` | search/filter |
| GET | `/api/leads/{customer_id}` | profile, memories, conversations, appointments, sentiments |
| PATCH | `/api/leads/{customer_id}` | `{status?, name?, email?, phone?}` |
| DELETE | `/api/leads/{customer_id}` | deletes customer + all related rows |
| DELETE | `/api/customers/{id}/memories?key=` | forget one or all saved facts |
| GET | `/api/leads/export.csv` | CSV (UTF-8 with BOM for Excel) |
| GET | `/api/appointments?upcoming=true&status=` | |
| POST | `/api/appointments` | `{customer_id, start_time, topic?, notes?}`; 409 `slot_taken` / `customer_has_appointment`, 422 `invalid_slot` |
| POST | `/api/appointments/{id}/cancel` | |
| POST | `/api/appointments/{id}/reschedule` | `{start_time}` |
| GET | `/api/knowledge/documents` | |
| POST | `/api/knowledge/documents` | multipart `file` (.pdf/.txt/.md, ≤ MAX_UPLOAD_MB); 415 wrong type, 413 too big |
| GET | `/api/knowledge/documents/{id}/chunks` | |
| DELETE | `/api/knowledge/documents/{id}` | |
| POST | `/api/knowledge/search` | `{query, top_k}` → results, found, method, top_score, threshold |
| GET | `/api/analytics/overview?days=14` | totals, distributions, top questions/objections/products, daily, weekly, upcoming, recent |
| GET | `/api/settings` | all settings + environment status (no secrets) |
| PUT | `/api/settings/{business_profile|agent_instructions|scheduling|lead_scoring|voice}` | validated (weights must sum to 100, etc.) |

## Example
```powershell
$c = Invoke-RestMethod -Method Post http://127.0.0.1:8000/api/conversations -ContentType application/json -Body '{"language":"en"}'
Invoke-RestMethod -Method Post "http://127.0.0.1:8000/api/conversations/$($c.id)/messages" -ContentType application/json -Body '{"text":"What is the refund policy?"}'
```
